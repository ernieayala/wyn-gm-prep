# 👉 Start Here — GM Prep Index

**📖 Index** · [Synopsis](gm_story_synopsis.md) · [Glossary](gm_glossary.md) · [Ch 1 →](gm_chapter_1.md)

> Landing page for the GM docs for *Jewel of the Indigo Isles*, a Battlezoo adventure path for Pathfinder 2e (levels 1–11). The docs teach: they explain what each scene does and the PF2 rules behind it, so you learn to GM while you run the campaign. Each chapter also has an eldamon companion doc that places befriendable eldamon from *Battlezoo Eldamon* into its scenes.

---

## Reading order

1. **[Synopsis](gm_story_synopsis.md)**: read once for the whole campaign, its twists, and when each lands.
2. **The chapter you're about to run.** Read it before the session, then run from it. Start with [Chapter 1](gm_chapter_1.md) and its [PF2 rules section](gm_chapter_1.md#pf2-rules-youll-use-all-chapter).
3. **That chapter's eldamon doc.** Each encounter names the scene it follows, so slot them into your notes. Read the [befriending rules](gm_chapter_1_eldamon.md#befriending-rules) once; every eldamon doc links back to them.
4. **[Glossary](gm_glossary.md)**: look things up as you go. Most entries end with an "At the table" hook.

## How these docs are built

Each chapter has two layers:
- **Run sheet:** stat lines, DCs, read-alouds, map tables. Scan it at the table.
- **Teaching layer:** callouts to read in prep and skip mid-session.

| Callout | What it tells you |
|---|---|
| **🎯 Why this scene exists** | The scene's job in the campaign |
| **🧩 Sets up** | Something that pays off in a later chapter |
| **📏 Rules refresher** | The PF2 rule in play, linked to the full version |
| **⚠️ Gotcha** | Easy to miss or get wrong, including book contradictions |
| **💡 GM tip** | A judgment call. Book rules are stated as rules |
| **🔒 GM-only** | A secret. Never read it aloud |

Each PF2 rule is explained once, in the first chapter that needs it, and later chapters link back (see the [rules index](#rules-index)). Page numbers are *Jewel of the Indigo Isles* pages, **BB** means the *Battlezoo Bestiary*, and **Eldamon p. N** means *Battlezoo Eldamon*.

Each eldamon doc lists the chapter's eldamon at a glance (element, rarity, DCs, the scene to insert after), then one entry per encounter: setup, how to find and recognize it, connection approaches, what makes it leave, outcomes, picked customization rolls, its 🔒 secret, and its 🧩 evolution condition.
