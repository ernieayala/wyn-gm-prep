# 👉 Start Here — GM Prep Index

**📖 Index** · [Synopsis](gm_story_synopsis.md) · [Glossary](gm_glossary.md) · [Ch 1 →](gm_chapter_01.md)

> This is the start page for the GM docs for *Jewel of the Indigo Isles*. It's a Battlezoo adventure path for Pathfinder 2e (levels 1–11).
>
> The docs teach as you go. They tell you what each scene is for and which PF2 rules it uses. You learn to GM while you run the campaign.
>
> Each chapter also has an eldamon doc. It places eldamon from *Battlezoo Eldamon* into that chapter's scenes, and the PCs can befriend them.

---

## Reading order

1. **[Synopsis](gm_story_synopsis.md)**: read it once. It covers the whole campaign, its twists, and when each twist comes out.
2. **The chapter you're about to run.** Read it before the session. Then run the game from it. Start with [Chapter 1](gm_chapter_01.md) and its [PF2 rules section](gm_chapter_01.md#pf2-rules-youll-use-all-chapter).
3. **That chapter's eldamon doc.** Each encounter names the scene it comes after. Add each one to your notes at that spot. Read the [befriending rules](gm_chapter_01_eldamon.md#befriending-rules) once. Every eldamon doc links back to them.
4. **[Glossary](gm_glossary.md)**: look things up as you play. Most entries end with an "At the table" tip.

## How these docs are built

Each chapter has two layers:
- **Run sheet:** stat lines, DCs, read-alouds, and map tables. Scan it at the table.
- **Teaching layer:** callouts. Read them when you prep. Skip them during the session.

| Callout | What it tells you |
|---|---|
| **🎯 Why this scene exists** | What the scene does for the campaign |
| **🧩 Sets up** | Something that pays off in a later chapter |
| **📏 Rules refresher** | The PF2 rule in play, with a link to the full rule |
| **⚠️ Gotcha** | Easy to miss or get wrong. This includes places where the book contradicts itself |
| **💡 GM tip** | Your call to make. When the book gives a rule, the doc says it's a rule |
| **🔒 GM-only** | A secret. Never read it aloud |

Each PF2 rule is explained once, in the first chapter that needs it. Later chapters link back to it. See the [rules index](#rules-index).

Page numbers:
- A plain page number is a *Jewel of the Indigo Isles* page.
- **BB** means the *Battlezoo Bestiary*.
- **Eldamon p. N** means *Battlezoo Eldamon*.

Each eldamon doc starts with a quick list of the chapter's eldamon. The list gives element, rarity, DCs, and the scene each one goes after. Then each encounter gets its own entry:
- setup
- how to find and recognize it
- ways to connect with it
- what makes it leave
- outcomes
- chosen customization rolls
- its 🔒 secret
- its 🧩 evolution condition
